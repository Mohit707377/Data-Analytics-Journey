## 3. Print Statement
The `print()` function is used to display output.

Example:
```python
print("Hello World")
```
## 4. Comments
Comments are used to explain the code and make it easier
to understand.
Python ignores comments while executing the program.

Single-Line Comment
A single-line comment starts with #.

Example:
# This is a comment
```python
print("Hello World")
```
The line starting with # will not be executed by Python.

Why Use Comments?
To explain what the code does
To make code easier to understand
To remember important information
To improve code readability

## 5. Variables
A variable is a name used to store a value in a program.
Python automatically identifies the data type based on
the value assigned to the variable.

Example:
```python
name = "Mohit"
age = 22
cgpa = 6.5
```
Here:
name stores a string
age stores an integer
cgpa stores a floating-point number

## 6. Data Types
A data type tells us what kind of value a variable stores.
Some common Python data types are:

1. int
Used for whole numbers.
age = 22

2. float
Used for decimal numbers.
cgpa = 6.5

3. str
Used for text or characters.
name = "Mohit"

4. bool
Used for True or False values.

is_student = True
Checking Data Type

We can use the type() function to check the data type.
age = 22
print(type(age))

Output:
<class 'int'>
